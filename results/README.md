# results/

`[CONFIRMED]` This directory is the credibility layer of the project (CLAUDE.md §16, §45.2:
"What was actually measured — `results/raw/`, nothing else").

| Directory | Contents | Mutability |
| --- | --- | --- |
| `raw/` | `RunResult` JSON, one per run | **Append-only. Never edit or delete (§33.2.1).** |
| `steps/` | Per-step Parquet telemetry, one per run | Append-only |
| `network/` | `NetworkProfile` JSON + raw `iperf3`/NCCL probe output | Append-only |
| `environment/` | `EnvironmentFingerprint` dumps (also embedded in each `RunResult`) | Append-only |
| `figures/` | Generated by `make figures` | **Safe to delete — regenerated, not authoritative** |

A wrong record is never edited. It is superseded by a new record under a new
`harness_version`, and the superseded one is noted in `RESULTS.md` (§16.3).

Nothing is committed here yet — no campaign has run (Phase 0, pre-implementation).
